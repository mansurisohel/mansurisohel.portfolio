Project Overview

Dental Care is a full-stack web application built to digitalise the appointment booking process for dental clinics. Patients get a seamless online experience — from exploring services to selecting doctors and booking slots. The admin panel gives the clinic team full control over appointments and patient data.

Key Features

  • Patient-facing appointment booking with form validation
  • Doctor profiles with specialisation and availability
  • Secure admin dashboard (CRUD for appointments)
  • MySQL-backed data persistence
  • Fully responsive layout — mobile to desktop
  • Font Awesome icons for rich visual hierarchy

Database Design

The MySQL schema includes tables for patients, doctors, appointments, and services, with proper foreign key relationships. PHP PDO is used for prepared statements, preventing SQL injection. Appointment status is tracked across three states: Pending, Confirmed, and Cancelled.

Learning Outcomes

This project strengthened server-side scripting with PHP, relational database design with MySQL, and session-based authentication. It also reinforced responsive CSS skills and the importance of server-side validation alongside client-side JavaScript checks.
