Project Overview

This project addresses a critical challenge in agriculture — early and accurate detection of plant diseases. Using a CNN trained in Google Colab on the PlantVillage Kaggle dataset, the system classifies leaf images into 38 categories of diseases and healthy states. The trained model is deployed in a web interface for real-time use.

Key Features

  • Real-time image upload and disease prediction
  • Supports 38 distinct disease & health classes
  • Deep learning CNN architecture (VGG / ResNet backbone)
  • Accuracy above 93% on the validation set
  • Prediction response time under 2 seconds
  • User-friendly web interface accessible on mobile

Challenges & Solutions

The main challenge was class imbalance in the dataset. This was addressed using data augmentation (flipping, rotation, zoom) and weighted class sampling during training. Overfitting was controlled with dropout layers and early stopping callbacks.

Impact & Results

Farmers and agronomists can now identify crop diseases early, reducing crop losses by enabling timely interventions. The model's 93%+ accuracy significantly outperforms traditional manual inspection methods, making it a viable decision-support tool for real-world agricultural use.
